CubeLab — стартовая версия 0.1

Содержимое:
- index.html — интерфейс
- style.css — оформление
- app.js — генератор тренировочных последовательностей и переключение разделов
- manifest.webmanifest — параметры установки
- sw.js — кеширование файлов для офлайн-открытия

ВАЖНО:
Генератор в этой стартовой версии создаёт тренировочные последовательности, но пока НЕ является сертифицированным WCA-генератором скремблов.
Раздел OLL/PLL пока является заглушкой. Случаи и алгоритмы будут добавлены только после проверки схем и алгоритмов симулятором.

Публикация:
Загрузить ВСЕ файлы из архива в корень отдельного GitHub-репозитория.
Включить Settings → Pages → Deploy from a branch → main → /(root).
Открыть опубликованный адрес по HTTPS. После первого открытия дать приложению загрузиться, чтобы Service Worker закешировал файлы.
